## 报告简介

本报告从**宏观周期、估值逻辑、资金面、技术扩散曲线与市场情绪**五个维度，系统比较 2020s AI 牛市与 2000 年互联网泡沫的异同，识别当前阶段的结构性特征与潜在风险，为投资决策与产业判断提供参考框架。

## 核心研究框架

| 维度 | 分析重点 |
| :-- | :-- |
| **宏观周期** | 利率环境、流动性周期、经济增长阶段的对比 |
| **估值逻辑** | PE/PS 估值体系、盈利兑现节奏、DCF 假设差异 |
| **资金面** | 机构持仓、散户参与度、杠杆水平、资金流向 |
| **技术扩散** | Gartner 曲线位置、商业化落地进度、生产率提升证据 |
| **市场情绪** | 媒体热度、IPO 市场、投机指标、恐惧贪婪指数 |

## 报告亮点

- **跨周期对比**：将 2020s AI 浪潮与 2000 年互联网泡沫置于统一分析框架
- **多维度交叉验证**：不依赖单一指标，从五个维度综合判断市场阶段
- **数据驱动**：基于历史数据与当前市场指标的量化比较
- **实操导向**：结论直接服务于投资决策与风险识别
